EXPERIMENT OVERVIEW
-------------------
This experiment simulates 1000 timesteps of synthetic
Kubernetes-style telemetry covering three injected anomaly scenarios
(burst hotspot, memory stress, network instability).
Sliding-window features (window=20) are extracted for
five core metrics (CPU, memory, net_in, net_out, latency).
LightKubeGuard uses an Isolation Forest (n_estimators=200,
contamination=0.05) trained exclusively on normal windows.
The threshold-based baseline flags timesteps where CPU>85.0%,
memory>90.0%, or latency>300.0ms.
